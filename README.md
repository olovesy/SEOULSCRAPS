# SEOUL SCRAPS — 서울사진수집일지

서울에서 발견한 정겹고 사소한 장면을 수집하는 로컬 문화 매거진 콘셉트의 반응형 웹사이트입니다.

사라진 장소, 오래된 물건과 기억에 남은 풍경을 개인 사진과 짧은 이야기로 기록했습니다.

## 프로젝트 개요

- 프로젝트명: SEOUL SCRAPS — 서울사진수집일지
- 유형: 개인 UX/UI 디자인 및 웹 퍼블리싱 프로젝트
- 주제: 서울의 장소, 생활문화와 기억 아카이빙
- 형식: 반응형 원페이지 웹사이트
- 작업 범위: 기획, UX/UI 디자인, 콘텐츠 구성, 퍼블리싱

## 페이지 구성

### Header — 도시 탐색 메뉴

도시 조각, 동네 탐색, 로컬 피플과 장소 제보 메뉴를 제공하는 상단 내비게이션입니다.

### Banner — 정겹고 사소한 도시의 조각

프로젝트의 주제와 대표 사진을 콜라주로 보여주는 첫 화면입니다. 사용자가 아래의 기록 콘텐츠를 탐색하도록 유도합니다.

### Contents — 이번 주에 주운 것들

서울에서 촬영한 사진과 짧은 이야기를 카드 형식으로 소개하는 주요 콘텐츠 영역입니다.

- **추억 속으로 사라진 홍대 놀이터**  
  그래피티와 음악, 사람들이 모이던 과거 홍대의 풍경을 기록했습니다.

- **브라운관 속에 멈춰 있는 시간**  
  서울의 한 박물관에서 만난 오래된 텔레비전과 라디오를 통해 생활문화의 변화를 보여줍니다.

- **서울의 풍경**  
  정확한 위치는 기억나지 않지만 인상에 남은 산과 기와지붕의 풍경을 담았습니다.

### Neighborhood — 동네 탐색

홍대, 종로, 안국과 우연히 만난 서울 등 지역과 주제별 도시 기록을 탐색하는 영역입니다.

### Submit — 장소 제보

사용자가 기억하고 싶은 장소와 사진 이야기를 직접 공유하도록 유도하는 참여 영역입니다.

### Footer — 프로젝트 정보

프로젝트 소개, 연락처, SNS와 사진 출처 정보를 제공하는 하단 영역입니다.

## 디자인 콘셉트

아날로그 스크랩북과 독립 잡지의 편집 디자인을 웹으로 표현했습니다.

- 찢어진 종이 형태의 이미지 프레임
- 회전하고 겹쳐진 사진과 메모
- 강한 원색과 종이 질감
- 스티커, 테이프와 손글씨 장식
- 자유로운 콜라주와 정돈된 콘텐츠 구조
- 데스크톱과 모바일에 대응하는 반응형 레이아웃

## UX/UI 설계

- 메뉴와 주요 버튼의 위치를 일관되게 유지
- 장식 요소와 클릭 가능한 요소를 명확하게 구분
- 사진과 짧은 이야기 중심으로 콘텐츠 구성
- 모바일에서 콜라주를 세로형 콘텐츠로 재배치
- 콘텐츠 탐색에서 장소 제보로 이어지는 흐름 설계

```text
도시 조각 발견 → 이야기 감상 → 동네 탐색 → 장소 제보
```

## 접근성과 사용성

- 시맨틱 HTML 태그 사용
- 이미지 역할을 하는 요소에 설명 제공
- 모바일 메뉴에 `aria-expanded` 적용
- 키보드로 접근할 수 있는 링크와 버튼 사용
- `prefers-reduced-motion`을 통한 모션 최소화 설정 대응
