# CITY SCRAPS — 도시채집일지

도시에서 발견한 정겹고 사소한 장면을 수집하는 로컬 문화 매거진 콘셉트의 원페이지 웹사이트입니다.

홍대 놀이터처럼 사라진 장소, 서울의 한 박물관에서 만난 오래된 물건, 정확한 위치는 기억나지 않지만 인상에 남은 서울의 풍경을 개인 사진과 짧은 이야기로 기록합니다.

## 프로젝트 개요

- 프로젝트명: CITY SCRAPS — 도시채집일지
- 유형: 로컬 문화 매거진 웹사이트
- 주제: 서울의 장소, 물건, 사람과 기억 아카이빙
- 형식: 반응형 원페이지 웹사이트
- 주요 문구: `도시에서 주운 정겹고 사소한 조각들`

## 디자인 콘셉트

아날로그 스크랩북과 잡지 편집 디자인을 웹으로 표현했습니다.

- 찢어진 종이 형태의 이미지 프레임
- 회전하고 겹쳐진 사진과 메모
- 강한 원색과 종이 질감
- 스티커, 테이프, 손글씨 장식
- 자유로운 콜라주와 정돈된 콘텐츠 구조의 조합
- 데스크톱과 모바일에 대응하는 반응형 레이아웃

## 주요 콘텐츠

1. 추억 속으로 사라진 홍대 놀이터
2. 서울의 한 박물관에 남아 있는 오래된 텔레비전과 라디오
3. 정확한 위치는 기억나지 않는 서울의 풍경
4. 지역별 도시 조각 탐색
5. 기억하고 싶은 장소 제보

## 실행 방법

별도의 설치 과정은 필요하지 않습니다.

1. 압축 파일을 해제합니다.
2. `city-scraps` 폴더를 엽니다.
3. `index.html`을 웹 브라우저로 실행합니다.

웹폰트를 사용하므로 인터넷에 연결되어 있으면 의도한 서체로 표시됩니다. 인터넷 연결이 없어도 콘텐츠와 개인 사진은 정상적으로 나타납니다.

## 사용 기술

- HTML5
- CSS3
- JavaScript
- CSS Grid 및 Flexbox
- CSS `clip-path`
- 반응형 미디어 쿼리

## 이미지 구성

사진은 `images` 폴더에 보관하며 CSS에서 불러옵니다.

```css
.image-store {
  background-image: url("images/hongdae-playground.jpeg");
}
```

사진을 교체할 때는 새 파일을 `images` 폴더에 넣은 후 `style.css`의 이미지 경로를 변경합니다.

```css
.image-store {
  background-image: url("images/new-photo.webp");
}
```

웹사이트 성능을 위해 최종 이미지 파일은 WebP 형식과 1600px 이하의 긴 변 크기를 권장합니다.

## 찢어진 이미지 효과

사진 자체를 찢어진 모양으로 편집하지 않고 CSS `clip-path`를 사용했습니다. 따라서 사진 파일을 교체해도 동일한 찢어진 종이 효과가 유지됩니다.

```css
.torn-paper {
  clip-path: var(--torn-edge);
  filter: drop-shadow(8px 10px 0 rgba(0, 0, 0, 0.24));
}
```

## 접근성과 사용성

- 시맨틱 태그인 `header`, `main`, `section`, `article`, `footer` 사용
- 이미지 역할을 하는 요소에 설명 제공
- 모바일 메뉴에 `aria-expanded` 적용
- 키보드로 접근할 수 있는 링크와 버튼 사용
- 동작 줄이기 설정에 대응하는 `prefers-reduced-motion` 적용
- 모바일에서 콜라주를 세로 콘텐츠 구조로 재배치

## 사진 저작권

현재 사용한 사진은 사용자가 제공한 개인 아카이브 이미지입니다. 포트폴리오 공개 전 다음 내용을 확인해야 합니다.

- 사진을 직접 촬영했거나 사용할 권한이 있는지 확인
- 식별 가능한 인물이 있다면 공개 범위와 초상권 확인
- 전시물과 박물관 내부 촬영 이미지의 온라인 공개 가능 여부 확인
- 제3자가 촬영한 사진이라면 촬영자 이름과 사용 허락 기록
